# Как помочь проекту / Contributing

## По-русски

Спасибо, что хотите помочь!

- **Ошибка или идея** — создайте [issue](../../issues/new/choose). Для ошибки укажите версию Windows, версию Скрина
  («Настройки → О программе»), что делали и что пошло не так. Журнал программы: `%APPDATA%\Skrin\skrin.log`
  (перед публикацией просмотрите — там названия ваших папок и звуковых устройств).
- **Правка кода** — fork → ветка → pull request. Запустите программу из исходников (`pythonw skrin.pyw`, см. README)
  и проверьте свою правку руками: скриншот, Ctrl+C, запись видео со звуком.
- Стиль: Python 3.12+, строки до 120 символов, комментарии по-русски или по-английски — как удобно.
  Интерфейс программы пока на русском; переводы (например, через словарь строк) — очень кстати.
- Одна правка — одна тема: так pull request проще проверить.

## In English

Thank you for helping!

- **Bug or idea** — open an [issue](../../issues/new/choose). For bugs include your Windows version, Skrin version
  ("Settings → About"), what you did and what went wrong. App log: `%APPDATA%\Skrin\skrin.log`
  (review it before posting — it contains your folder and audio device names).
- **Code changes** — fork → branch → pull request. Run the app from source (`pythonw skrin.pyw`, see README) and test
  your change by hand: screenshot, Ctrl+C, video recording with sound.
- Style: Python 3.12+, lines up to 120 characters, comments in Russian or English.
  The UI is in Russian for now; translations (e.g. via a string table) are very welcome.
- One topic per pull request — it makes review easier.
